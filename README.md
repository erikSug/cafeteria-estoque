# cafeteria-estoque
Controle de Estoque (Cafeteria)

Criar uma automação em Python utilizando a biblioteca ReportLab para gerar 
um boletim rápido de inventário e nível de suprimentos de uma cafeteria. 

O projeto deve incluir uma página web limpa (HTML e CSS) estruturada em blocos modernos, 
contendo um botão interativo que permita visualizar imediatamente o PDF compilado pelo script.

Dinâmica de Trabalho e Fluxo Git:

Definição do Tech Lead: Cada grupo deve escolher um integrante para assumir o papel de Tech Lead.

Criação do Repositório: O Tech Lead será responsável por criar e estruturar o repositório
oficial do projeto.

Distribuição de Tarefas: O Tech Lead define as tarefas/issues e gerencia o escopo 
do projeto entre os membros da equipe.

Desenvolvimento via Fork:

Os desenvolvedores realizam o fork do repositório oficial para suas contas pessoais.

As implementações e correções são desenvolvidas individualmente ou em duplas nesses forks.

Entrega (Pull Request): Para integrar as funcionalidades ao projeto oficial, 
os desenvolvedores abrem Pull Requests direcionados ao repositório do Tech Lead.

Publicação em Produção: Após a revisão e validação, cabe exclusivamente ao 
Tech Lead realizar o merge e subir a aplicação final para a branch principal (main/master)
